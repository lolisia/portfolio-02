# Android 실기기 수정·프로파일링 (2026-11-14)

## 사용자 요청 반영

- 패널은 게임 위에 펼쳐진다. 열림/닫힘에 따른 카메라 v_offset·portrait_scale 변경 제거.
- 별을 화면 픽셀 단위로 그린다. 모바일에서 작은 각도의 `acos(dot())`가 0으로 반올림되어 큰 점이 되던 계산 제거. 줌에도 크기 유지.
- 최대 줌 3.3 → 12.0. 휠·핀치 모두 동일한 상한.
- 성능을 숨기던 모바일 자동 해상도 저하 제거. 수동 선택한 품질의 렌더 스케일 유지.

## 측정 환경·방법

USB 연결 기기 `2511FPC34G` / ARM Mali-G720 MC8 / Vulkan Forward Mobile. 화면 1268×2756, Godot 논리 뷰포트 390×848. 기존 모바일 기본 품질 1, 3D 스케일 0.85, MSAA 2x 유지. CPU 렌더 준비 시간과 GPU 타임스탬프를 함께 수집했다.

동일한 초기 시점·낮·패널 닫힘에서 전후 각각 2구간을 측정했다. 각 구간은 8초 워밍업 후 8초 수집. 게임의 캐릭터·날씨 애니메이션은 계속 실행했다. 프로파일러는 opt-in debug 전용이며 설정 파일은 사용 후 소비한다. 일반 실행에서는 동작하지 않는다.

| 지표 | 기존 | 수정 후 |
|---|---:|---:|
| 구간 1 FPS | 27.41 | 31.09 |
| 구간 2 FPS | 25.04 | 29.16 |
| 평균 프레임 시간 | 38.20ms | 33.23ms |
| 프레임 시간으로 환산한 FPS | 26.18 | 30.10 |
| 평균 GPU 시간 | 36.46ms | 31.51ms |

FPS 환산 기준 약 15.0% 향상, GPU 시간 13.6% 감소. 두 구간의 마지막 draw call/primitive 수도 각각 전후 동일(419 / 586956, 393 / 583780)이었다. 진단 때만 효과를 숨겼으며 최종 APK에는 물·안개·그림자·식생을 그대로 유지했다.

원본 측정: [baseline.json](baseline.json), [optimized.json](optimized.json). `process_ms`는 Godot TIME_PROCESS 모니터의 원값으로 렌더 대기 등을 포함할 수 있으므로 순수 GDScript CPU 시간으로 해석하지 않았다. 전력/DVFS와 발열을 고정한 실험실 측정은 아니므로 구간 변동을 함께 공개한다.

## 병목과 최적화

초기 진단에서는 기본 약 21.9 FPS / GPU 43.8ms였다. 3D 제거 시 약 62 FPS, 식생 제거 시 약 32 FPS, 그림자 제거만으로는 거의 개선되지 않았다. 추가 진단에서 물을 숨기면 약 33.7 FPS, 안개를 숨기면 약 31.6 FPS였다. 이 값들은 다른 시점의 대조 검사이며 위 전후 수치와 직접 혼합하지 않는다. [초기 진단](diagnostics-initial.json), [추가 진단](diagnostics-final.json).

반영한 최적화:

1. 풀 눌림 영향 영역의 보수적 경계를 계산한다. 영역 밖에서는 원래도 기여가 0이므로 16슬롯 정점 루프를 건너뛴다. 영향 범위·모양 유지.
2. 폭포 물방울 900개의 transform/color를 MultiMesh 단일 버퍼로 업로드한다. 개수·궤적·크기·색 유지.
3. 눈이 없을 때 결정 반짝임의 3D 노이즈를 계산하지 않는다. 텍스처 재질에서 쓰이지 않는 절차적 요철 계산도 생략한다.
4. 두 방향 광원에서 중복되던 구름 그림자 값을 fragment당 한 번 계산한다.
5. 목재·회벽은 웹 원본 재질 생성식을 텍스처/노멀로 구워 재사용한다. 재질 디테일을 삭제하지 않고 반복 연산을 텍스처 조회로 바꾼다. 기존 석재·기와·나무껍질도 유지한다.
6. 배경 쿼드 뒤의 화면용 하늘 렌더를 제거한다. 하늘은 환경광·반사 소스로 유지한다. 이 항목만의 유의미한 속도 개선은 측정되지 않았다.

식생 alpha-depth-prepass 실험은 속도 이득이 없어 최종 코드에서 제외했다. 해상도·식생 수·물방울 수·그림자 품질을 낮추는 방법은 최종 최적화에 사용하지 않았다.

## 검증과 한계

- 실기기 밤/열린 패널 캡처 확인: 작은 별, 게임 화면 고정. 밤+열린 패널 측정은 약 28 FPS였다([night.json](night.json), GPU 타이머 비활성).
- 스모크, 캐릭터/카메라 parity, 마우스·터치 입력, 모바일 회귀 검사 통과.
- 모바일 회귀 검사: 패널 전후 카메라 transform/size/v_offset 동일, 12배 줌, 물방울 버퍼 좌표·색, 풀 눌림 보수 경계 확인.
- APK v0.1.1 (code 2), 세로 고정, ARM64/ARMv7. 서명·16KB 정렬 검사 후 연결 기기에 설치.
- **60 FPS는 달성하지 못했다.** 최종 측정에서도 GPU가 약 31.5ms를 사용한다. 물·안개·복잡한 재질의 GPU 비용이 남아 있으며, 추가 기기 검증과 렌더 경로 개선이 필요하다. 다른 시점·날씨·확대 화면까지 같은 FPS를 보장하지 않는다.
