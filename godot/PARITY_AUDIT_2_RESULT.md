- Godot 4.7.2 import와 기존 `res://tools/smoke_test.gd` 통과. 최종 로그에 스크립트/폴리곤 오류 없음.
- 추가 `res://tools/parity_test.gd` 통과: 최대 140초 분량의 실제 일정·이동·충돌 루프, 집에서 2m 이상 이동, 비가 오면 문턱까지 귀가, 마우스·터치 방향, 웹 close-up 오프셋, 수평 거품 검사.
- Forward+ 실제 렌더: 폭포, 닭장, 겨울 정원, 밤 패널, 360×800 비 패널, Low 겨울 캡처 검사. 웹 Chrome의 falls/coop/garden 캡처와 대조.
- 고해상도 패널: 3840×2160 요청, Windows 창 영역 제한으로 실제 3840×2141. `--ui-scale 2`에서 패널 폭 1300px 확인.

## 남는 차이와 검증 범위

- 렌더러의 반사·그림자·대기·톤매핑 때문에 전체 픽셀/색상이 같다는 판정은 하지 않는다. 폭포 반사광과 물보라 노이즈, 식생의 배치·밝기는 대조 캡처에서도 차이가 있다.
- Godot 글자 그림자는 약화한 네이티브 그림자이며 CSS의 흐린 그림자 2겹과 동일하지 않다.
- OS 200% 배율 자동 감지는 이 환경에서 별도 실측하지 않았다. 고해상도 검사는 `--ui-scale 2`로 수행했다. OS가 scale/DPI를 잘못 보고하는 경우 이 옵션을 사용할 수 있다.
- 360px 검사는 PC 창에서의 레이아웃 검사이며 모바일 실기기 성능·터치 검증을 대체하지 않는다.
- 겨울 잎은 웹과 같이 식물 인스턴스 단위로 사라진다. 잎 카드별 점진 제거로 변경하지 않았다.

## 사용자 재확인 후 수정

- **캐릭터 A-Pose**: GLB의 절대 타임스탬프(Walking 첫 키 2.67초)를 Godot import 전에 0초로 정규화했다. importer가 앞부분에 기본 포즈를 채우던 문제를 해결했다. 반복 클립의 수평 root motion도 웹과 같이 고정했다. `convert_unitychan_glb.py`와 변환된 GLB를 함께 갱신했다.
- **캐릭터 매몰**: bind-pose 메시 AABB 대신 Standing을 적용한 스킨 정점 경계를 측정한다. 월드 지형 높이를 제외한 캐릭터 로컬 좌표로 크기와 발바닥 오프셋을 계산한다.
- **접힌 UI 헤더**: 펼치기/접기를 헤더 전체 높이에 세로 중앙 정렬하고 12px, 흰색 alpha .94로 키웠다.
- **invalid RID 해제**: resize/품질 변경으로 엔진이 종속 uniform set을 자동 폐기하면 RID 값은 남을 수 있다. `uniform_set_is_valid()`로 실제 생존 여부를 확인한 뒤 해제·재생성한다.
- **풍속계**: 구 메시를 뚜껑 없는 반구 메시로 교체하고 안쪽 면도 렌더한다.
- **폭포 하단**: 중심에서 불연속인 방사형 좌표 이동을 없애고 연속적인 두 노이즈의 이동과 부드러운 가장자리로 거품을 변경했다. 거품 광택도 제거했다.
- **맵 바위**: 거칠기를 무시하던 고정 Phong 하이라이트를 석재에서 제거했다. 둥근 SphereMesh 대신 웹의 반경 .52 dodecahedron을 사용한다. 폭포 바위는 별도 메시를 유지한다.

추가 검증: Walking 첫 300ms의 다리 회전 변화·변형 후 발바닥 높이 검사 통과. 실제 Forward+에서 창 크기/품질 조합을 아홉 번 바꾸는 `tools/render_regression_test.gd` 통과(최종 로그 오류 없음). 걷기·풍속계 컵·폭포·접힌 UI 근접 캡처 확인.

## 카메라 입력 변경

- 좌클릭·한 손가락 드래그: 지면 XZ 평면 이동. 줌·카메라 각도에 맞는 이동량으로 화면상의 지점을 끌어 이동한다.
- 우클릭(좌우 동시 클릭 포함)·두 손가락 드래그: 카메라 회전. 두 손가락 중심의 이동량을 마우스와 동일하게 적용한다.
- 휠·핀치: 포인터/두 손가락 중심의 지면 위치를 유지하며 줌.
- 두 손가락 이벤트는 프레임 단위로 묶어 대칭 핀치 중 일시적인 회전을 막는다. 손가락 개수 변경 때 기준을 갱신한다.
- UI 위에서 버튼을 놓거나 포커스를 잃어도 입력 상태를 해제하며, 터치에서 생성된 가상 마우스 이벤트의 중복 처리를 막는다. 초기 시점 복원은 이동한 중심점도 복원한다.
- `tools/camera_input_test.gd`: 마우스/터치 이동·회전량 일치, 핀치 배율·중심 유지, UI 위 해제, 두 손가락→한 손가락 전환, 포커스 해제, 시점 복원 검사 통과. 기존 스모크·parity 검사 통과.
